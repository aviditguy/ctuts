* Exponents
  
*** Laws of Exponents

      - $a^1 = a$

      - $a^0 = 1$

      - $a^{-n} = \frac{1}{a^n}$

      - $a^m \cdot a^n = a^{m+n}$

      - $\frac{a^m}{a^n} = a^{m-n}$

      - $(a^m)^n = a^{m \cdot n}$

      - $(ab)^m = a^m \cdot b^m$

      - $\left(\frac{a}{b}\right)^m = \frac{a^m}{b^m}$

      - $a^{\frac{m}{n}} = \sqrt[n]{a^m} = (\sqrt[n]{a})^m$


      Remember this one  $\longrightarrow 2^3 \cdot 3^3 = (2 \cdot 3)^3 = 6^3 = 216$

      In *C* we have the ~double pow(double base, double exponent)~ function from ~<math.h>~ we can use it works for
      any =base > 0= *for all real base and exponent*.
      #+BEGIN_SRC C :includes '(<stdio.h> <math.h>)
	  printf("%lf\n", pow(2, 5));
	  printf("%lf\n", pow(2, -3));
	  printf("%lf\n", pow(9, 0.5));
	  printf("%lf\n", pow(2, M_PI));
      #+END_SRC

      
*** Lets Write our own ~pow~ function

***** Handle Positive Integer Only

       - ~int64_t my_pow(int64_t base, int64_t exponent)~ will be signature of our function
       - We will at first only deal with positive *base* and *exponent*

****** Naive Method O(n) Complexity

        This is extremely slow imaging *exponent = 100000* these large numbers this will take forever, *very bad approach*
        #+BEGIN_SRC C :includes <stdio.h>
	  int64_t my_pow(int64_t base, int64_t exponent){
	    int64_t result = 1;
	    for (int i=0; i<exponent; ++i)
	      result *= base;
	    return result;
	   }
        #+END_SRC

****** Better Approach O(log n) Complexity
        
******* *Recursive Approach*

         Compute: $a^n = a \times a \times a \times a \dots \times a \quad \text{(n times)}$
	 Instead of multiplying one by one we use the *binary representation of exponent*.

	 *Key Properties*:
	 - if $n$ is even: $a^n = (a^\frac{n}{2})^2$
	 - if $n$ is odd: $a^n = a \cdot a^{n-1}$

	 This means we can reduce the problem by about half at each step: *logarithm complexity O(log n)*
	 #+BEGIN_SRC C :includes '(<stdio.h> <inttypes.h>)
	   int64_t my_pow(int64_t base, int64_t exponent){
	     if (exponent == 0) return 1;
	     if (exponent == 1) return base;

	     if (exponent % 2 == 0){
	       int64_t half = my_pow(base, exponent/2);
	       return half * half;
	     } else{
	       return base * my_pow(base, exponent-1);
	     }
	   }

	   int main(void){
	     printf("%ld\n", my_pow(7, 22));

	     return 0;
	   }
	 #+END_SRC
